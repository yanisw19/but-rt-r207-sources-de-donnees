# R207 – Sources de données

Fil rouge : une base de données de gestion de **bibliothèque** sous PostgreSQL.

| Fichier | Contenu |
|---|---|
| `TP2_Creation-base-PostgreSQL.pdf` | Démarrage de PostgreSQL, création de la base et des tables depuis un script SQL, insertion des données (`psql`) |
| `TP3_Requetes-SQL-simples.pdf` | `SELECT`, `WHERE`, `DISTINCT`, jointures simples |
| `TP4_Requetes-SQL-complexes.pdf` | Calculs, regroupements (`GROUP BY`), conditions avancées |
| `TP5_Programmation-Python-SQL.pdf` | Interface Python connectée à PostgreSQL : consultation, ajout, suppression |

**Mots-clés :** PostgreSQL, SQL, Python.
